### Mandatory Workflow on Any Change:
Setiap kali ada perubahan, penambahan fitur, revisi teks, atau modifikasi file di project `portfolio-izza`:
1. **Verifikasi Build**: Jalankan build check dengan Bun (`bun run build`) untuk memastikan tidak ada error sintaks atau runtime.
2. **Git Commit**: Commit perubahan dengan pesan commit yang jelas dan deskriptif (`git add .`, `git commit -m "..."`).
3. **Auto-Push ke GitHub**: Wajib langsung lakukan `git push origin main` agar Vercel secara otomatis mendeteksi perubahan dan melakukan re-deployment secara instan ke `https://portfolio-izza.vercel.app/`.
